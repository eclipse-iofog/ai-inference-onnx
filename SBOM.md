# Software Bill of Materials

Generated by `licensegen`. Do not edit by hand. Regenerate with `make sbom`.

This file describes the **source tree**: the Go modules the engine and the dashboard compile, and the ONNX Runtime and provider SDK versions each image is built from. It is not the SBOM of one image. The pushed engine image carries a registry attestation. A GitHub release ships one CycloneDX file and one SPDX file for each CPU runtime archive. Those files add the file hashes. Publishing a runtime image writes the pair next to that architecture's digest.

`sbom.cdx.json` and `sbom.spdx.json` list required and optional components that have a version. They omit excluded modules, which are not compiled into a shipped binary. They also omit components that have no version of their own. Those stay in the inventory below and in `LICENSE-3RD-PARTY.md`.

Container image attestations are not in this document.

## Runtime pins

Versions are read from `scripts/build-onnxruntime.sh`. The engine loads `libonnxruntime.so.<version>` at run time and does not link it. Provider SDK libraries ship in the engine image. The runtime image is the ONNX Runtime library built against that SDK. `tensorrt13` uses a different TensorRT, CUDA, and cuDNN pin on arm64 than on amd64.

ONNX Runtime is MIT. `licenses/LICENSE` and `licenses/ThirdPartyNotices.txt` ship in the runtime image. CUDA, cuDNN, and TensorRT use the NVIDIA license texts recorded below. The CUDA runtime license is also staged as `/licenses/cuda-cudart-LICENSE`. OpenVINO is Apache-2.0. MIGraphX is the MIT text from the ROCm tree, and those license files are copied to `/licenses`. Qualcomm QNN is the Qualcomm AI Stack license, staged as `/licenses/Qualcomm_LICENSE.pdf`.

Full license texts are in `LICENSE-3RD-PARTY.md`.
