# Documentation

Read the [user guide](user-guide/) from the first page to the last. Each page assumes the pages before it. When you finish, you can place a model, call it on REST, gRPC, and NATS, and run the container on a node with authentication, a device, and a read-only root filesystem.

The [reference](reference/) is the lookup. Use it when you already know which fact you need: a configuration key, a subject, a metric name, an image tag, or the catalog file.
